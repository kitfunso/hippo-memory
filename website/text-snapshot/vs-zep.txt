hippo vs Zep
Zep is a managed context service for agents, built on Graphiti, its open-source temporal knowledge graph. Its self-hosted Community Edition is deprecated, so Zep today means Zep Cloud, or your own cloud on the Enterprise plan. Hippo runs on your machine with no account, and wires itself into the coding agents it finds.
The one test both have numbers on
On DMR, a public memory test of N questions, Zep publishes N and hippo scored N when we ran it with its local reranker on. The setups differ. A whole-chat baseline that is published at N scored N in our run, so the size of the gap is rough. Zep's published score is higher, and we have not run Zep under the same conditions. Zep's other published scores vary by source, so we quote none of them here.

Both keep the old fact
Graphiti gives facts validity windows and invalidates old ones instead of deleting them. Hippo links a superseded memory to its replacement and leaves it out of recall, and hippo recall --as-of <date> shows what was current on a given day.
What Zep ships today
Zep Cloud is the product, and Enterprise customers can run it in their own cloud. There is no self-hosted Zep, because Community Edition is deprecated and no longer supported. Graphiti is Apache-N if you want to build your own, and it needs a graph database and defaults to OpenAI for inference and embeddings. Zep's MCP server is hosted and needs sign-in (Zep's pages (opens in new tab), checked N September N).
When to pick which
Pick hippo
Pick hippo when the memory is for coding agents on your machine, and you want no account, graph database or model to run.
Pick Zep
Pick Zep when you want a managed service that turns business data, documents and conversations into a knowledge graph for your agents, with someone else running it.

Can I still self-host Zep? +
Not Zep itself. Zep's FAQ says Community Edition, the version you could host locally, is deprecated and no longer supported (checked N September N). Graphiti, the open-source framework under Zep, runs anywhere, and needs a graph database and a language-model key.
