hippo vs Letta: a Letta alternative for coding agents
Letta, formerly MemGPT, now builds Letta Code, a stateful agent harness whose memory lives in blocks the agent edits itself. Hippo is memory for the agents you already run, such as Claude Code, Codex and Cursor, in one store they share.
Both keep memory where you can see it: Letta Code tracks its context in git, and hippo writes markdown mirrors you can commit. They differ in who edits memory. In Letta, the agent rewrites its own blocks with built-in tools. In hippo, memories come from hooks, the CLI and MCP tools, and you can mark a recalled one wrong or supersede an old fact.

What Letta ships today (checked N-N-N)
Letta Code, Apache-N installed with npm install -g @letta-ai/letta-code. You connect your own model API keys with /connect (Letta Code (opens in new tab)).
Without signing in, "your agents are stored only on local disk"; /login backs them up to Letta's cloud (quickstart (opens in new tab)). All context, memory blocks included, is tracked in git (Letta Code (opens in new tab)).
In Letta's legacy VN SDK, memory blocks are what the agent reads and updates with built-in tools. Writing a block replaces its whole content, and when two processes write the same block at once, the last write wins (VN SDK memory blocks docs (opens in new tab)).
A hosted MCP server, used with a Letta API key, that lets an MCP agent create and message your Letta agents (docs (opens in new tab)).
The original Letta server, the MemGPT line, is retired to an archive branch of letta-ai/letta (opens in new tab). Letta Code has a free plan that uses your own API keys, and paid plans from $N a month (pricing (opens in new tab)).
When to pick which
Pick hippo
You already use Claude Code, Codex or Cursor and want them to share one store of lessons that you can correct, on your machine with no account.
Pick Letta
You want a coding agent whose memory is part of the agent, one that edits its own memory blocks, and you are ready to switch agents to get it.

hippo and Letta, asked directly
Is Letta the same as MemGPT? +
Letta grew out of MemGPT; its GitHub README calls it "Letta (f.k.a. MemGPT)". Active development has moved to Letta Code, a stateful agent harness, and the original Letta server now sits on an archive branch (checked N-N-N).
Is hippo a Letta alternative? +
It depends on what you want from Letta. Letta Code is a stateful agent harness with its memory built in. Hippo is memory for the agents you already use: Claude Code, Codex, Cursor and any MCP client share one store, on your machine with no account, and you can mark a lesson wrong or supersede an old fact. If you want an agent that manages its own memory blocks, that is Letta Code.
