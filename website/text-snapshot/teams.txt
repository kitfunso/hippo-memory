Hippo for teams is planned. Here is what exists today.
The commercial edition is planned; its private repository is a scaffold, not a released enterprise product.
What you can run today
The MIT core includes an HTTP server with tenants, API keys, admin and member roles, per-key scope grants and an audit log on every change. Keys are stored scrypt-hashed, and one API call deletes a memory. Slack and GitHub connectors bring in what your team has already written down.
What is planned
SSO, SCIM, SIEM export, a hosted service and an SLA are planned, with Jira and Notion connectors next. None of it is released.
How we would measure it with you
The fair test is a holdout, where a random share of sessions runs without memory and you compare cost per merged PR and repeat errors between the two groups. We have no team result to show. If your team wants to try, open an issue and tell us what you'd need.
