Enterprise vN · in development · pilots open The memory layer your platform team can approve.
The commercial edition is planned; its private repository is a scaffold, not a released enterprise product. One plugin turns on shared memory for every agent seat. It runs inside your network, recalls only what each developer can already see, and logs every write. No usage beacon, nothing sent home.
