Two commands, then carry on working
Hippo is an MIT-licensed npm package with zero runtime dependencies. It needs Node N or later, no account and no API key.
$ npm install -g hippo-memory $ hippo init Copy
hippo init creates a .hippo/ store in the project, adds a short block to an existing CLAUDE.md or AGENTS.md, installs Claude Code's hooks and schedules a daily run at N:Nam that stores lessons from the day's commits. --no-hooks and --no-schedule skip those parts. hippo init --scan ~ gives every git repository under your home folder a store.
Installing the package alone captures nothing, and what runs after init depends on the agent. Codex runs hippo's hooks only once you trust them in /hooks. hippo doctor checks the install.
What each agent gets
Claude Code gets a block in CLAUDE.md and seven hooks. Codex gets a block in AGENTS.md and two hooks. Cursor and Pi read the AGENTS.md block, OpenClaw and OpenCode use a plugin, and any MCP client can run hippo mcp.
Four commands you can run yourself
$ hippo remember "deploy failed: forgot migrations" --error Copy
Stores a memory. Errors get twice the half-life.
$ hippo recall "why did the deploy break" --budget N Copy
Returns the matches that fit a token budget.
$ hippo outcome --good Copy
Marks the last recall as useful.
$ hippo sleep Copy
Merges related memories and lets unused ones fade.
