What hippo does between sessions
When you state a rule or a tool call fails, hippo keeps it.
At the start of the next session your rules are printed back to the agent, and memories that match each prompt are added. In our test that came to about N tokens a session.
When a memory turns out wrong, hippo outcome --bad pushes it down the ranking and hippo supersede replaces it. Unused memories fade on a N-day half-life.
hippo init sets this up for Claude Code, Codex, Cursor and three more agents, and any MCP client can use the server. What runs automatically differs by agent.
How each part works
Stored on your machine, and what can leave it
Memories live in SQLite, in .hippo/hippo.db in each project and a global store in ~/.hippo/, with markdown mirrors you can read, grep and commit. The package has zero runtime dependencies. Recall makes no network call by default. Text leaves your machine only if you turn on an API embedder or a reranker, run hippo refine, or have ANTHROPIC_API_KEY set when hippo sleep runs, and one config line switches that last one off.
Who should use something else
Hippo is for one developer's coding agents on one machine. MemN fits better when the memory belongs to your app's end users, Zep when you want a managed knowledge graph built from business data, and Letta Code when you want an agent that edits its own memory.

Do I still need CLAUDE.md? +
Yes, for short standing rules such as build commands and code style. Claude Code's memory docs (opens in new tab) say that when two rules contradict each other, Claude may pick one arbitrarily. Hippo holds the lessons that pile up and recalls the ones that match the task.
What does hippo cost? +
Nothing. Hippo is MIT-licensed and needs no account or API key. Optional features that call an outside provider bill through it. The Jev reranker costs about N USD a recall, and API embedders and sleep's fact extraction use your own keys.
Try it on the repository you have open
Run two commands, and hippo doctor will name anything that's missing. If hippo misses a rule you expected it to keep, open an issue with an example.
$ npm install -g hippo-memory Copy
$ hippo init Copy
Installing the package alone captures nothing, and what runs after init depends on the agent.
