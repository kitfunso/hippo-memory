NEach prompt gets what's relevant
Your pinned rules, plus up to N memories that share its words.
NA wrong memory gets weaker
After a bad answer, hippo outcome --bad weakens the memories behind it.
NA new fact replaces the old
With hippo supersede, the old one leaves recall but stays on record.
NUnused fades, pinned stays
Unused memories weaken over a year or two, and pinned ones never fade.
N What hippo does
Capture. Rules and errors from each session, found by word patterns.
SessionEnd hook
Recall. Keyword search with no model or network call, and --why shows the match.
hippo recall "why did the deploy break" --why
Outcomes. A bad mark weakens a memory, and each recall keeps it longer.
hippo outcome --bad
Mirror. A markdown copy of every memory to grep, commit and review.
.hippo/
Dashboard. Memory health by project, on localhost.
hippo dashboard
Git history. Learns from the last N days of commits, then each day's.
hippo learn --git
Sleep. Merges related memories and stores faded ones, ready to restore.
hippo sleep
Import. Brings in the notes your agents already keep, unchanged.
hippo import --agents

Questions
Why hippo when there are other memory tools?
It runs locally with no extra language model, keeps memory in files you can read, and serves every agent from one store.
Does my code leave my machine?
Recall is offline by default, and text only leaves through settings you switch on, or hippo sleep when ANTHROPIC_API_KEY is set.
Do I still need CLAUDE.md or AGENTS.md?
Keep them for short standing rules. Let hippo hold the lessons.
Will it miss things?
A rule without never, always or must can be missed, so pin it with hippo remember "…" --pin.
