What we measured, and where hippo lost
We built hippo and ran these tests, so read them as a vendor's numbers. We ran rivals on the same answer model where we could. Scores marked published come from each team's own setup, so we give no ranks.
Repeat mistakes in real Claude Code sessions
Each run corrects Claude Code once and then, N to N tasks later, gives it a task where the same mistake is possible. We ran it on N repositories, registered first (opens in new tab).

The chart counts first chances N to N tasks after the correction. The registered measure, the first chance in each mistake family over N units, gives N points fewer repeats with hippo [N N], at the same cost, a ratio of N [N N]. On tasks with no lesson to apply, neither the cost nor the share solved changed.
What this run can't tell us is why. With lesson capture removed the result was the same, so we can't say hippo's lessons caused it. Round N tests that. The corrections were scripted, the agent was Claude Code only, and the test code and run records are not in the public repo. The round before was inconclusive, at N points fewer on N repositories.

Finding the right session
On LongMemEval-S, hippo's benchmark scripts put an answer session in the top five for N% of N questions with the free local MiniLM embedder. That is the best of five settings, chosen after the run, on a measure close to its ceiling. Requiring every answer session, the same runs score N to N%, and gbrain is ahead at N% with a paid reranker. The hippo recall command on a default install scores N% [N N]. On one store of all N sessions, recall fell to N% in June N
What the two rerankers bought
--reranker cross-encoder reorders the top N memories with a free model on your machine, and is off by default. On DMR (the score file, opens in new tab) it lifted hippo's answers from N with the embedder alone to N by N points [N N]. On PersonaMem vN and HotPotQA-N the change was within the noise.
--reranker jev sends the top candidates to the hosted TypeSafe Jev API, and is off by default. On N developer queries from a private store, the right memory ranked first for N% of them, against N% with the free local cross-encoder. Three graded-answer tests (opens in new tab) showed no better answer rate. It buys a shorter context for about N USD a recall, and it sends your query and candidate text to a third party.
What didn't work
Sleep lowered recall by N points [N N] on one scorer and raised it a little on another, so we claim no benefit for it.
Decay made no measurable difference, on a synthetic test that gives a N-day half-life little time to act.
The old N-day default was a bug that cost recall, so the default moved to N days.
Seven smaller experiments failed, stalled or were thrown out, among them a correction detector at N precision against a N bar.
One early headline number did not reproduce, and we retracted it.
