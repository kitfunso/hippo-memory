### Fixed

- **Decisions, incidents, policies and the other objects no longer fade faster than ordinary memories.** Their writers pinned each memory to a flat 90 days, a value set when the default was 7 days. When 1.46.0 moved the default to 365 days, a decision, incident, process, policy, skill, project brief or customer note began fading four times faster than an ordinary note, and a `defaultHalfLifeDays` set in `.hippo/config.json` never reached them. A store's first `hippo sleep` on 1.52.7 moves each memory of a live object still on 90 days to the default, keeping its recall bonus, and records each old value in the audit log. From then on every object writer takes the configured default the way `hippo remember` does. On a store made before 1.52.7 they keep writing 90 days until that sleep, which moves those memories with the rest. Predictions, and every writer on a new store, take the default from the first write. The memory of a superseded or closed object stays at 90 days, as does a half-life hippo shortened or one set by hand.
