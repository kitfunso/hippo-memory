### Changed

- BREAKING: **What a store can do now comes from the groups it sets, not from its `kind`.** Three new optional store groups carry the work that used to check `kind === 'sqlite'`: `localFiles` (the store's hippo.db folder), `auditMaintenance` (the quality audit, its repairs and audit-log prune) and `lessonWrites` (git learn). A store without `localFiles` gets the request fence, 501 on `POST /v1/sleep` and the other local-only routes, and no auto-sleep. `auditMemoryQuality`, `removeAuditErrors`, `repairMemoryQuality`, `repairMemoryQualityOnce`, `pruneAuditLog` and `learn` now return a Promise and reject with `StoreNotPortedError` (501) on a store without their group. MCP `hippo_learn` runs on any store with `lessonWrites`. `remember` now returns `halfLifeDays` and `tags`, so MCP `hippo_remember` no longer reads the row back. See `docs/UPGRADING-2.0.md`.
