### Fixed

- **Session capture no longer reads another project's transcript.** When no transcript could be found for a session, `capture --last-session` and the session-end hooks fell back to the newest transcript under `~/.claude/projects/`, whichever project it belonged to, and saved memories from it into the current project's store. That happened when the transcript named by `--transcript` or by the hook payload was missing, when a payload named none, when the Codex session-end hook found no Codex transcript, and when `session-end` could not start its background worker. Now the first source present is the only one tried: a named transcript that is missing, or a hook payload without a readable one, skips capture. The newest-transcript scan runs only on a manual run, with no `--transcript`, no stdin payload, and a stdin read that did not time out.
