### Security

- **`hippo dashboard` now needs a per-start access token (behaviour change).** Each start mints a random token and prints the URL once, as `http://localhost:<port>/?token=<token>`. Open that URL: the dashboard sets an HttpOnly, SameSite=Strict cookie and the rest of the session works as before. A request without the token or the cookie, page or `/api/*`, now gets a 401. Before, any local process or user could read every memory through the loopback port. The Host-header and cross-site checks are unchanged, and so is the `hippo serve` API.
- **Authenticated routes check the credential before they read the body.** Every `/v1/*` handler with a JSON body used to read and parse up to 1 MB before it looked at the Authorization header, so an unauthenticated caller could make the server wait on and buffer a large upload. The 401 now comes first, and the body reader takes the resolved auth context, so a new handler cannot reverse the order. The 1 MB cap and its 413 are unchanged.
- **The rate-limit key reads a forwarded chain from the right (behaviour change), and a new `HIPPO_TRUSTED_PROXIES` setting pins the proxy.** With `HIPPO_CLIENT_IP_HEADER=x-forwarded-for`, the key used to be the first entry, which the client writes, so each request could pick a fresh bucket. It is now the rightmost entry that no trusted proxy added. Set `HIPPO_TRUSTED_PROXIES` to a comma-separated list of proxy IPs or CIDRs to read the header only from those peers and to skip their hops. Without `HIPPO_CLIENT_IP_HEADER`, forwarded headers are still ignored and the socket address is the key. Single-value headers such as `cf-connecting-ip` and `fly-client-ip` behave as before.
- **`/mcp/stream` caps concurrent streams per client.** Each API key (or each client IP when keyless) may hold 8 open SSE streams; the next one gets a 429 until one closes. Set `MCP_SSE_MAX_STREAMS` to change the cap.
- **The Codex wrapper no longer lets cmd.exe expand `%NAME%` in forwarded arguments.** On Windows, `hippo codex-run` runs a `.cmd` shim through cmd.exe, which expands `%PATH%` even inside double quotes. Each `%` is now escaped outside the quotes, and cmd runs with delayed expansion off, so every argument reaches Codex as typed.
