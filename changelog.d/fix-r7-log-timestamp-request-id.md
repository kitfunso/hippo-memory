### Fixed

- **Every log line says when it was written and which request it was written for.** A `[hippo] level: message` line carried no time, and only the handful of lines that were handed a request id by hand carried one, so a warning from deep inside a recall could not be tied to the call that caused it. Each line now ends its message with `ts=<ISO time>`, and every line written while `hippo serve`, the dashboard or an MCP stdio call handles a request also carries `requestId=<id>`, the same id the `X-Request-Id` response header returns. `HIPPO_LOG_FORMAT=json` writes each line as one JSON object (`ts`, `level`, `msg`, then the fields) for a log collector; the text line stays the default. A script that matches a whole log line to its end needs to allow the new fields.
