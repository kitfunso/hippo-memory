### Changed

- **The block `hippo init` writes into `CLAUDE.md` and `AGENTS.md` no longer asks for a closing step.** Agents ran `hippo remember` or `hippo outcome --good` as a separate tool call just before their final answer, and each extra call re-reads the whole context. `hippo outcome --good` is gone from every block, so agents no longer send that reinforcement signal; you can still run it yourself or call the `hippo_outcome` MCP tool. The Claude Code block also drops its session-end `hippo capture` step and its plain `hippo remember "<lesson>"` step, because the `SessionEnd` hook already runs `hippo capture` on the session transcript. Every block keeps `hippo remember ... --error`, now worded to run at the moment something goes wrong, never as a closing step; OpenCode's also still asks for lessons, since no hook captures its sessions. Every block keeps `hippo context --auto` at task start. Agents with no hook that captures the session keep their capture step: Cursor, OpenClaw, OpenCode, Pi, and Codex without its wrapper.
- **Re-running `hippo init` refreshes an old block.** Init used to skip any file that already had a hippo block, so existing installs kept the old text. It now swaps in the current block when the text between hippo's markers matches, after trimming whitespace, a block an earlier hippo wrote, and prints one line for each file it refreshes. An edited block stays as it is, with a one-line hint that `hippo hook install <agent>` replaces it. Text outside the markers is never touched.
