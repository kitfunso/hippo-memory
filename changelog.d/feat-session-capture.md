### Added

- **`hippo-memory/session-text` exports `collectSessionTurns`, `sessionTail` and `scrubForSharing`, with no store, database or server in its imports.** A hook client reads a Claude Code transcript with the same code `hippo capture --last-session` uses. `scrubForSharing(text)` redacts secrets, masks email addresses as `[email]`, and replaces each home-directory path (Windows, macOS, Linux, WSL and Git Bash forms) up to and including the user name with `[home]`, so the user name stays on the machine.
- **`hippo-memory/server` exports `captureSessionTexts` and the types `SessionCaptureRequest`, `SessionCaptureResult` and `CallerProject`.** `captureSessionTexts(ctx, { sessionId, project, texts })` stores what `hippo capture --last-session` stores for the same transcript turns and returns `{ captured, skipped, rejected }`. Rows go to `ctx`'s store and tenant, carry the caller's project name and session id, and are audited as `ctx.actor.subject`; the store's own folder never names the project. The texts are scrubbed again with `scrubForSharing`. A text that a row of the caller's project or a user-global row already holds is skipped; rows of other projects and other tenants do not count. It writes no stats, computes no embeddings, prints nothing and never exits. It throws `BadRequestError` for an empty project name, more than 30 texts, a text over 32 KiB or more than 256 KiB in all, and on the same session id and project name caps as `promptHookContext`. It keeps the newest 50 items and counts the rest as skipped.
- **`promptHookContext` takes `printedHash` and returns `staticHash`, so a caller that prints the reply itself skips the pinned block only after it printed it.** `staticHash` is the hash of the pinned block in this reply's `stdout`, or `null` when the reply holds none, for a sub-agent and for a holdout session. The caller sends it back as `printedHash` on the next prompt of that session. The block is left out only when `printedHash` matches the current block and the `pinnedInject.refreshTurns` rule allows it; with no `printedHash` the block is sent, so a lost reply or a cleared session gets its rules back. A `printedHash` that is not 16 lowercase hex characters throws `BadRequestError`. `hippo context` is unchanged.

### Fixed

- **The SessionEnd hook no longer crashes when its background worker fails to start.** A spawn failure such as `EAGAIN` arrived as an `'error'` event with no listener, which Node treats as an uncaught exception. It is now logged as a warning.
