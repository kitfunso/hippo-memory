### Added

- **Add the Z0 set X runner, where each lesson's apply tasks run in Codex.** `ab-run.mjs` now runs the four Codex arms of prereg 85: X1 (built-in memory), X2 (hippo in Claude Code and Codex on one store), X3 (a stub that imports `AGENTS.md`) and X4 (the taught lessons written into `AGENTS.md`). Teach tasks stay in Claude Code. Each apply runs `codex exec` in a per-run Codex home, reads usage and turns from Codex's rollouts, and runs the G1 read check over them. X2 installs hippo for Codex inside each run and waits for the end line of hippo's session-end worker before the surface snapshot. If the install changes your own Codex launchers, the runner puts them back and abandons the run. Your Codex login is copied once and sits in a run only while a session runs; a run killed by Ctrl-C can leave the copies behind. A file the run writes that holds the login is deleted, and the run stops. The four slow Codex test files run in the token-eval workflow. No hippo default changes.
