### Added

- **`serve()` takes a `publicJson` option, so an add-on can publish fixed JSON that any caller can read without a key.** It maps a plain `/v1/` path to a JSON value. A `GET` on that path answers 200 with the value, `content-type: application/json` and `cache-control: no-store`. The server checks no key, reads no request body and never touches the store, so the path also answers under a store other than `hippo.db`. The value is serialized once at boot, and later changes to the object are not served. `serve()` refuses to start on a path that is not a plain `/v1/` path, on a path a core `GET` route already serves, and on a value over 64 KiB once serialized. `HEAD`, `POST` and other methods on the path answer as they did before. The rate limiter counts these requests like any other `/v1` request. Anyone can read the value, so it must hold nothing secret.
