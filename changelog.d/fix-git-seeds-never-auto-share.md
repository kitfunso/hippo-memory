### Fixed

- **Memories seeded from git history no longer copy themselves into the global store.** `hippo init`, `hippo sleep` and `hippo learn --git` turn matching commit subjects (fixes, reverts, refactors and the like) into memories tagged `error` and `git-learned`. The `error` tag alone lifted each one over the automatic sharing bar, so the first `hippo sleep` (with `autoShareOnSleep`, on by default) copied every seed into the global store, and one project's commit subjects turned up in other projects' context. Automatic sharing, in `hippo sleep` and `hippo share --auto`, now skips any memory tagged `git-learned`. Sharing one by hand still works: `hippo share <id>` and `hippo promote <id>` copy it as before. Copies already in the global store stay where they are. They keep the `git-learned` tag, which `hippo recall "<words>" --json` run in another project shows in each result's `tags` (in the project the seed came from, recall shows the local row instead). To remove one, run `hippo reject <id> --global --reason "<why>"`, which deletes the global copy and keeps that text out of the global store from then on.
