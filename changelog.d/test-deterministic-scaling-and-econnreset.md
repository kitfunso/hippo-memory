### Tests

- **The half-life migration's scaling test no longer reads a clock.** It timed two store sizes and compared them, and a shared runner that slowed one side failed it in nine CI runs. It now counts what the migration does. One test records the SQL: one indexed update per memory moved and the same number of other statements at 20 and at 400 memories. The other measures the JS heap the migration allocates for 250 and for 1,000 memories, which is 4 times as much for linear work and 54 times as much when the audit record is copied once per memory.
- **Tests that need the CLI to route to a running server no longer depend on the health probe's timer.** The CLI writes to the store directly when the server's `/health` answer misses the probe deadline, so a slow runner made `tests/cli-econnreset-no-replay.test.ts` see a direct write where it expected a routed one. That file and `tests/cli-thin-client.test.ts` now set `HIPPO_HEALTH_PROBE_MS` past their own time limit, so only the server's answer picks the route. 30 of 30 local runs passed with 48 busy processes on 24 cores.
