### Added

- **Add the Z0 G5 regrade, the reader sample and the stored sample.** `scripts/token-eval/z0-regrade.mjs` runs every saved lesson check and acceptance test again on the saved commits (prereg 166), records each verdict change as a flip, and writes the `grading.json` that `z0-analyze.mjs` reads. A failed harness gate is an error row that the next run retries, and a stopped regrade resumes. The `reader` mode draws a seeded, blinded sample of diff and lesson pairs and scores the labels; the `stored` mode does the same for the prereg 179 check of the stored judgement and reports agreement, a Wilson interval and kappa. `grade.json` now records whether the final check ran. `z0-analyze.mjs` prints the stored-sample line when `grading.json` holds it. No hippo default changes.
