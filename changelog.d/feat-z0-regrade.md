### Added

- **Add the Z0 G5 regrade, the reader sample and the stored sample.** `scripts/token-eval/z0-regrade.mjs` runs every saved lesson check and acceptance test again on the saved commits (prereg 166), records each verdict change as a flip, and writes the `grading.json` that `z0-analyze.mjs` reads. A failed harness gate is an error row that the next run retries, and a stopped regrade resumes. The `reader` mode draws a seeded, blinded sample of diff and lesson pairs and scores the labels; the `stored` mode does the same for the prereg 179 check of the stored judgement and reports agreement, a Wilson interval and kappa. `grade.json` now records whether the final check ran. `z0-analyze.mjs` prints the stored-sample line when `grading.json` holds it. A checker's identity is its entry script, that script's extension, the local files it imports and its args. A moved results folder reads as unchanged. The harness reads imports with the `typescript` parser and stops the load on an import it cannot hash. A reader round that passes freezes the checkers: `regrade --post-fix` and `grading` refuse a checker that the round did not judge. `grading` and each reader draw also refuse post-fix rows from two versions of one checker. No hippo default changes.
