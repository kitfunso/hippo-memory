### Security

- **Injection screening of Slack and GitHub content now catches disguised forms of the phrases it already knew.** A phrase could be slipped past the screen with a zero-width character or a soft hyphen inside a word, full-width or mathematical letters, a Cyrillic or Greek look-alike letter, an HTML character reference such as `&#105;`, or a tab or a second space inside a fixed phrase. Connector content is now checked twice: as written, and as a reader sees it. The stored text is never changed, and a held memory carries the same `pattern:<name>` reason the plain phrase gets.
- **Connector content with a bidi override, embedding or isolate control is held for review, with the reason `pattern:bidi-control`.** These controls reorder what is shown without changing the bytes. Ordinary Arabic and Hebrew text has none. A path copied from the Windows file properties dialog starts with one, so a message carrying such a path is held.
- **Some connector content that was stored before this release would now be held for review.** New content of that kind goes to the quarantine queue (`hippo quarantine list`) until an admin approves or rejects it; memories already stored are not rescreened. Still not caught: a paraphrase, another language, a phrase broken across two lines, look-alike letters outside the Cyrillic and Greek table, and encodings such as base64.
