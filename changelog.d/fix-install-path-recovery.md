### Fixed

- **`hippo hook install codex` finishes an install that stopped after it moved the Codex launcher aside.** If hippo stopped between the rename and the wrapper write, the `codex` command was gone and the next install could not find Codex. The install now finds the leftover `*.hippo-real*` backup beside the empty launcher slot and completes. `hippo hook uninstall codex` also puts the backup back when no metadata was written. A launcher slot that holds a real Codex is never touched.
- **The daily schedule entry is matched exactly.** A commented-out line or a longer task name no longer counts as scheduled. A marked crontab line with an outdated command is rewritten in place and keeps your schedule; `hippo init` prints the old and the new line, and any duplicate marked line is removed and printed. The manual crontab line now carries the marker, so a pasted line is recognised next time. On Windows a `schtasks /query` timeout no longer falls through to a create.
- **A change to a shipped instruction block now fails CI until its hash is listed.** `scripts/checks/check-hook-block-hashes.mjs` requires the hash of every current block text in the shipped list, so `hippo init` keeps refreshing unedited old blocks. One missing early OpenClaw block hash was added.
