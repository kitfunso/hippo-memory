### Fixed

- **`hippo tokens` now counts the block `hippo compact-resume` restores after compaction.** Claude Code puts that block into the model's context, like the per-prompt hook's, but the ledger never booked it. It is now its own `compact_resume` surface, booked under the hook payload's session id, and the hook still never creates a store.
- **`hippo tokens` now counts what later model calls re-read.** A block of memory text stays in the conversation, so each later model call reads it again until the host compacts. When a Claude Code session ends, hippo counts the session's model calls in its transcript and books those re-read tokens per surface, before sleep and capture run; counting a session again replaces the earlier count. `hippo tokens` adds a re-read column, re-read totals and how many sessions were counted (`--json` adds the same fields), and `hippo doctor` reports tokens sent and re-read. A session still open, or one that crashed, shows sent only. Re-reads usually bill at the provider's cached-input rate, a fraction of the full input price. Counts are still estimates (characters / 4).
