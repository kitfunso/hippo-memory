### Breaking

- **The package root no longer exports raw store functions.** `initStore`, `writeEntry`, `loadAllEntries`, `readEntry`, `deleteEntry`, `loadIndex`, `rebuildIndex`, the session, conflict, handoff and card functions, the embedding stores, `embedMemory`, `embedAll`, the sharing and git-learning functions, working memory and the audit store took a folder, opened hippo.db and skipped the tenant, actor and audit checks every api function applies. Use the CLI, the HTTP routes or `sqliteStore(hippoRoot)` from `hippo-memory/store-kit`. `docs/UPGRADING-3.0.md` has one row per group. `deduplicateLesson`, `searchBoth`, `promoteToGlobal`, `wmFlush`, `loadIndex`, `rebuildIndex`, `loadCardDeps`, `loadCardComments` and `loadLatestHandoffForCard` had no caller outside tests and are deleted, so no hippo path writes `index.json` any more.
