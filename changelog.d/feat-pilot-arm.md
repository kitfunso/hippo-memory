### Added

- **A pilot holdout arm for measuring hippo against a live control group (CD11).** Set `{"pilot":{"holdoutRateBp":2000}}` in `config.json` (basis points, 0 to 10000, default 0 = off). Each session is assigned `hippo` or `holdout` by a hash of its id, and the first hook call writes one `token_ledger` row (`surface='pilot'`, `event='arm'`, `block_hash` = the arm, `items` = the rate). A holdout session gets empty output from the per-prompt hook, the SessionStart hook and `hippo compact-resume`; capture hooks still run. The agent's own `hippo context` pull is gated in Claude Code only, so Codex holdout sessions still get memories from it (an open leak, see the decision record). Sub-agents write no row and follow the parent's arm. `hippo recall`, the HTTP API and the MCP tools are not gated and write no arm row; the MCP context tool is offered to agents as a start-of-session call, so it acts like an unrecorded push. Token summaries and `hippo doctor` skip the arm rows; doctor adds one `pilot` line when the rate is above 0. No schema change. Details: `docs/decisions/2026-10-03-pilot-arm.md`.
