### Changed

- **The previous session's consolidation log no longer goes into the model's context.** The SessionStart hook runs `hippo last-sleep`, which printed the sleep and capture log from the last session on stdout, and Claude Code adds SessionStart stdout to the context the model reads. The log is for you, not the model, so it now prints on stderr, which Claude Code writes to its debug log instead: start `claude --debug` and read `~/.claude/debug/<session-id>.txt`. Hooks installed by `hippo hook install claude-code` pick this up on upgrade with no reinstall. The plugin's SessionStart hook no longer throws stderr away, and the plugin is now 0.6.1.
- **A memory with a copy in the global store is injected once.** `hippo share` and `hippo promote` copy a memory into the global store under a new id, so the pinned rules and recent memories sent with every prompt, and the strength-ranked context used when there is no query, could carry the same text twice, once plain and once marked `[global]`. hippo now keeps one copy of each: a pinned copy wins, then the stronger one after the discount the ranking already gives global memories, and a tie keeps the local copy. Budgets are unchanged; a recent-memory slot the second copy used to fill goes to the next memory in line. The same rule covers memories the per-prompt hook recalls by the prompt, which also skip the text of a pin already injected.
- **`hippo recall --multihop` and `hippo recall --hops` return one copy of a shared memory.** `--multihop` ranked the local and global stores as one list, so both copies could come back; `--hops` could reach the global copy of a memory it had already returned.

### Fixed

- **`hippo sync` no longer copies a promoted or shared memory back into the project it came from.** Sync skipped global memories by id only, and a promoted or shared copy has a new id, so each sync added a second local row with the same text. It now also skips a global memory whose text the project already holds. Rows an earlier sync added stay until you remove them.
