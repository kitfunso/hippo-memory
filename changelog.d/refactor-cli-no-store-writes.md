### Changed

- **Internal:** `hippo watch`, `hippo audit --fix`, `hippo refine`, `hippo decide --supersedes` and the session-end re-read count no longer call the store's `writeEntry`, `deleteEntry` or `openHippoDb` from `src/cli/`. `watch` stores its failure through `api.remember`. `audit --fix` and the sleep audit share `removeAuditErrors` in `src/api/audit.ts`. `refine` stores a rewrite through `storeRefinement` in the new `src/api/refine.ts`. `decide --supersedes` weakens the old memory through `weakenSupersededMemory` in `src/objects/decisions.ts`. `recordRereads` in `src/store/token-ledger.ts` now takes the store root and opens it. `scripts/check-cli-recall-writes.mjs` fails when a CLI file names a memory writer or the store opener. It names three files that still do, each with its reason: `quality-repair.ts`, `projects.ts` and `sleep.ts`. Stored rows, audit rows, printed output and exit codes are unchanged, which `tests/cli-maintenance-writes-parity.test.ts` pins.
