### Added

- **`hippo recall`, `hippo outcome` and `hippo context` take `--global`.** With the switch each verb reads or writes the global store (`$HIPPO_HOME` or `~/.hippo/`) alone, whatever folder it runs in, as `hippo sleep --global` already does. Without it nothing changes. A caller with no project folder, such as a chat host, can now recall, mark outcomes and build hook context from the one store it writes to.
- **`hippo outcome --id <id>` can be given more than once.** One call marks every id and prints the total applied. An id outside the caller's tenant is skipped, as before.
- **`collectSessionTurns` reads plain `{"role", "content"}` lines.** A JSONL line with no `type` key, a `role` of `user` or `assistant` and a non-blank string `content` now gives one turn, so a chat host can hand `hippo capture --transcript` its messages as they are. Lines with a `type` (Claude Code, Codex, Copilot) read as before. `collectSessionTurns` is exported from `hippo-memory/session-text`, so an integrator's transcript with such lines now gets turns where it got none.
