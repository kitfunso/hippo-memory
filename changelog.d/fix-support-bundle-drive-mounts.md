### Fixed

- **`hippo support-bundle` removes your user name when a log line writes your home the Git Bash, Cygwin or WSL way.** The 1.52.3 notes said the bundle swapped your home folder in every spelling a log line uses. It did not: it only knew a drive written `C:`, so `/c/Users/<name>`, `/cygdrive/c/Users/<name>` and `/mnt/c/Users/<name>` kept your user name in a bundle made with `--include-logs`, and Claude Code on Windows runs its shell commands in Git Bash. On Windows the bundle now matches the part of your home below the drive, such as `\Users\<name>`, wherever it appears, so a mount or network share it does not know also loses your user name and keeps only its own prefix in front of the `~`. A home one folder below its drive, such as a custom `HOME` of `D:\home`, swaps only after that drive, since other paths can hold a folder of the same name.
