### Security

- **A new API key is a member key that expires after 90 days unless you ask for something else.** `hippo auth create` and `POST /v1/auth/keys` used to mint an admin key that never expired whenever the role was left out. Now a mint with no role makes a member key, and a mint with no expiry makes a key that stops working 90 days later. Ask for the wider key by name: `--role admin` for an admin key, `--ttl-days <n>` for another lifetime (at most 3650 days), `--no-expiry` for a key that never expires. Over HTTP the same choices are `"role": "admin"`, `"ttlDays": <n>` and `"noExpiry": true`; in the Python client they are `role="admin"`, `ttl_days=<n>` and `no_expiry=True`.
- **The mint tells you what it made.** The CLI prints `role:` and `expires:` lines (`"role"` and `"expiresAt"` with `--json`), and names on stderr each default it took. The HTTP reply carries `role` and `expiresAt` (`null` for a key that never expires), and the `auth_create` audit row records both.
- **Upgrading.** Keys you already have are not changed: their role stays, and a key with no expiry still has none. What changes is the next mint. A script that runs `hippo auth create` or posts `{}` to `/v1/auth/keys` and then calls an admin route (`/v1/sleep`, `/v1/quarantine`, minting a key, revoking another key) gets a `403` until it asks for `--role admin` or `"role": "admin"`. A key minted with the default lifetime answers `401 invalid api key` from day 90; mint its replacement before then, or pass `--no-expiry`. The first key of a store gets no special treatment: the CLI on the host needs no key, so `hippo auth create --role admin` always works there.
- **The first key with an expiry stops hippo older than 1.64.0 from opening that store.** Those releases ignore the expiry and would keep honouring an expired key, so the store refuses them from the first default mint on. If another machine or tool shares the store with an older hippo, upgrade it first or mint with `--no-expiry`. `docs/ARCHITECTURE.md` (section `src/db/migrations/v53.ts`) has the way back.
