### Fixed

- **A token budget now bounds the text that reaches the model, and every token figure counts that text.** `hippo recall`, `hippo context` (the per-prompt hook included), `hippo assemble`, `hippo drill`, the MCP tools and the HTTP routes spent their budget on memory content alone, then printed each memory with its label, date, tags and strength under a heading. A store with long tags could print a block well over its budget, and the heading and `hippo tokens` reported the smaller content figure. Each surface now prices a memory by the line it prints as, pays for the heading and hint lines too, and chooses within that. The heading's token figure and the ledger row are the estimate of the printed block. A block at the same budget may now carry fewer entries than before. Recall still keeps its first `--min-results` memories (default 1) and the MCP recall tool its top memory, even one larger than the budget; context skips a memory that does not fit and keeps filling; assemble never evicts the fresh tail and drill always keeps its first child. JSON output picks the memories the text form would print. The exported `multihopSearch` now fits what it returns to the requested budget and `minResults`; it could return twice the budget or more.
