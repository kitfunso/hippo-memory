### Added

- **Each ended session now leaves one short digest memory, written without a model call.** With no API key, session-end capture kept only sentences that match keyword patterns, so the plain-prose account of what was wrong, where, and what fixed it was lost, along with the list of files the session touched. The Claude Code and Codex session-end workers now store up to five whole sentences from the agent's final message, ranked by whether they name a place in the code or give a reason, plus a `Changed:` line with the repo-relative files whose edits applied. Sentences that repeat a prompt or something hippo injected, open on a word pointing outside the sentence, ask a question, or name a home directory are left out; secrets are redacted, email addresses are masked, Claude Code's own error and usage-limit notices are never read as the closing message, and the digest stays under 1200 characters. Paths are checked against the repo without ever probing a network share or a host named in a URL. The digest is written only in a folder with its own hippo store, never to the global store; it is tagged `session-digest`, is never shared automatically, is left out of consolidation, and is not shown next to the session handoff that already carries the same closing message. Re-running session end for the same session rewrites the row in place, which also clears any pin, star, retrieval count or supersession on it. `hippo reject <id> --reason "<why>"` blocks that exact text: a re-run that produces the same digest stays out, but one with a different closing message is written again.

### Fixed

- **Captured memories and the session handoff no longer store raw email addresses.** Capture from any source and the handoff's task, summary and next step now mask them as `[email]`, after secret redaction; asset names such as `logo@2x.png` and version pins such as `react@18.2.0` are left alone.

- **A captured never / always / must rule keeps its subject.** "We must never push master to origin" was stored as "must never push master to origin"; it is now stored from the start of the sentence. A lead over 300 characters or a keyword inside brackets keeps the old form. "Whenever" no longer counts as "never".
