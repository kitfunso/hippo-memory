### Changed

- **The hippo block for Codex, Cursor, OpenClaw, OpenCode and Pi asks the agent to save what it learns with `hippo remember` again.** These tools have no auto memory of their own, so with only the error line in the block, nothing but errors reached hippo: decisions, user preferences and lessons were lost when the session ended. The block now also says to run `hippo remember "<what you learned and why>"` as soon as the agent learns something that should outlive the session, and the OpenCode block no longer tags every lesson `--error`, which doubled its half-life and raised its score for sharing with other projects. The line tells the agent to leave out secrets and personal details, since `hippo remember` stores what it is given as is. The OpenCode guide's memory skill had the same `--error` on every lesson and is fixed too, and the README, Codex and OpenClaw guides now describe the new line. The Claude Code block is unchanged, because Claude Code's own auto memory does this job there. Re-running `hippo init` refreshes a block nobody edited; an edited block stays as it is, with a hint.
