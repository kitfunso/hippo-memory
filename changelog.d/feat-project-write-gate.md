### Added

- **`serve()` takes a `projectWriteGate` that can refuse a write under a caller's project.** It is asked before `remember()` stores a row from POST /v1/memories or MCP `hippo_remember`, after the project name passes the usual check. A string answer refuses with 403 and that text. Add-on routes call `admitProjectWrite` from `hippo-memory/server`. `hippo-memory/project-identity` now exports `assertCallerProject`. It also exports the types `ProjectWriteCall` and `ProjectWriteGate`. Personal writes never reach the gate. A gate that throws gives 500, and an answer that is not null or a non-empty string refuses with 403 and a default text.
