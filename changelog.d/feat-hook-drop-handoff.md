### Changed

- **The Claude Code and Codex prompt hook no longer prints another session's handoff.** The hook (`hippo context --pinned-only --format additional-context`) used to send a Session Handoff pointer (about 190 characters) on each prompt where another session had an unfinished handoff. It now prints only the handoff of its own session. To resume another session's work, run `hippo context --auto` or `hippo handoff latest --session=<id>`. The Copilot session start (`--format copilot`), `--format json`, markdown, the HTTP route, MCP and the default of `promptHookContext` are unchanged. A caller of `promptHookContext` opts in with `ownHandoffOnly: true`. A shared store follows the same rule. With no session id, the hook leaves every handoff out. The saving is not measured yet; a Z0 rerun will confirm it. See `docs/decisions/2026-11-01-hook-drops-other-session-handoff.md`.
