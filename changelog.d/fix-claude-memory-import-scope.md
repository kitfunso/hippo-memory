### Fixed

- **`hippo init` and `hippo sleep` import only the project's own Claude Code memory.** They copied the auto memory of every project on the machine, every folder under `~/.claude/projects`, into the current project's store, where each note counted as this project's memory and came back in its recall. They now read only the folder Claude Code keeps for this project, found by Claude Code's own rule: the checkout the project sits in, which its subfolders share, or the project folder outside a repository. Linked worktrees share with their main checkout, or with the repository's git folder when it sits outside a checkout (a bare repository, or `--separate-git-dir`). Notes an earlier version copied from other projects stay in the store. They carry the `claude-code-memory` tag, and `hippo forget <id>` removes one.
