### Fixed

- **`hippo sleep` keeps both versions of a fact until one is retired.** Sleep merged look-alike memories, such as two services on different ports or the old and new value of a changed setting, into one row that kept only the longer text, then shortened the half-life of every original. It merged the same memories again on each later sleep, so the originals faded out and one of the two values was gone. The merged row now holds the full text of every original and records which memories it came from, and a memory that is already merged is not merged again. The dedup step of sleep, and `hippo dedup`, removed a memory when most of its words matched another's, so a changed port, version or name counted as a copy. They now remove a memory only when its text matches another's apart from spacing.
