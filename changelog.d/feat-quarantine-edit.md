### Added

- **Edit a held memory from the review queue.** `hippo quarantine edit <id> "<text>"` and `POST /v1/quarantine/:id/edit` (admin only; a member key gets 403) approve a held memory with the admin's cleaned text. The text runs the write screen again and answers 400 when it still reads as an instruction, alone or joined to the kept lead-in. A held row whose own lead-in reads as an instruction answers 400 too, because an edit keeps the lead-in: reject that item instead. Clean text sent twice, or an approve after an edit, answers 409. The held row stays as delivered and is superseded by a new memory that lists it in `parents`, keeps the lead-in of the held row the edit read plus its artifact, trust tags and confidence tier, and sits under the original scope. One `quarantine_edit` audit row records `{originalScope, newId}`.

### Changed

- **`hippo quarantine` shows a held item as pending review.** The stored status stays `pending`, so `GET /v1/quarantine` is unchanged.
- **`remember` screens the lead-in joined to the content.** A connector write whose instruction splits across the two is held, and a member's shared write split the same way is framed. Any Unicode space, invisible mark (`Default_Ignorable_Code_Point` or `Cf`), control character (`Cc`), or Braille blank (`U+2800`) at the join is ignored.
- **The write screen reads every hidden mark both ways.** A hidden mark or control character inside a word, between words or at the lead-in join no longer hides a phrase, whatever mix of marks the text uses: each mark reads as nothing or as a space on its own. A mark counts raw or as a character reference. A reference spelled as master read it (`&#` and up to 7 decimal digits or `&#x` and up to 6 hex digits, each with a semicolon, and the five XML names) decodes to its character. Any other spelling (no semicolon, more digits, a blank name such as `&ZeroWidthSpace;` or `&shy;`, `&nbsp` or `&shy` with no semicolon) decodes only when its character is blank or the number names no character; otherwise it stays as written, so `&#46`, `&#124` and `&#000000082;` are text. A name with a semicolon that is in no table and starts with `shy` or `nbsp` decodes that prefix and keeps the rest as text (`&shytions;`). A reference is decoded once, a name outside those lists stays as written, a raw line break inside a phrase still ends the phrase, and a soft hyphen after a keyword syllable can flag hyphenated prose.
- **Store port:** `Quarantine` gains an optional `editQuarantined`; a store without it answers 501 for an edit.
- **501 store-port text:** `StoreNotPortedError` now reports `the '<storeKind>' store has no port for '<group>'; this code path is not ported to the store yet`, so the wording fits both port groups and single methods.
