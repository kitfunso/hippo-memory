### Added

- **Opt-in `clef-flash` and `clef` rerankers.** `hippo recall --reranker clef-flash` (or `clef`) sends the same request the Jev reranker sends to Cloudflare Workers AI, using `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN`, or to a private CLEF server named by `HIPPO_CLEF_ENDPOINT`. The reply must name the requested model and score every candidate from 0 to 1. On any failure the reranker keeps the native order and warns once; it never falls back to paid Jev and never reorders part of the list. Each result records the backend, the requested and reported model, token usage and any fallback reason. No reranker runs by default, and no benefit is claimed yet: the CLF12 comparison has not run. `scripts/rerank-3arm-ab.mjs` takes `RERANK_ARM=clef-flash|clef` for that comparison.
