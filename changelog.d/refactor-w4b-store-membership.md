### Changed
- **Internal:** `src/store` now holds only code that runs SQL on hippo.db, plus its row shapes, SQL text and adapter. Scope predicates moved to `src/core/recall-scope.ts` (their SQL twins `scopeAdmitSql` and `touchableScopeSql` joined `src/store/rule-sql.ts`), the markdown mirror format to `src/core/markdown.ts`, typed-object shapes to `src/core/object-types.ts`, `RejectedValueError` to `src/core/api-errors.ts`, the YAML frontmatter codec to `src/util/yaml.ts`, hook payload parsing to `src/util/hook-payload.ts`, `chunked` to `src/util/chunked.ts`, and the embedding providers to the new `src/embeddings/` folder. Every published name keeps its export from `.` and `./server`. `scripts/check-store-port.mjs` gains `storeFilesWithoutSql`, a pinned list of `src/store` files that run no SQL, so a new pure helper filed there fails CI. CLI value imports from the store fell from 64 to 55.
