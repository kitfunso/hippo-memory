hippo github backfill --repo <owner/name> [--since ISO] [--max <N>]
  --repo   GitHub repository in owner/name format (required, e.g. acme/widgets)
  --since  Initial high-water-mark for first run (optional, ISO 8601)
  --max    Cap items per stream (optional, integer)
  Auth: GITHUB_TOKEN with repo read scope, or a GitHub App: GITHUB_APP_ID,
  GITHUB_APP_PRIVATE_KEY_FILE (the path to its .pem) and GITHUB_APP_INSTALLATION_ID
  (optional; else looked up for the repo). A fully set App wins over GITHUB_TOKEN.
  Set GITHUB_ENTERPRISE_URL=https://<host> to backfill from GitHub Enterprise Server.
  Also set GITHUB_ENTERPRISE_BARE_REFS_HOST=<host> only if the store took webhooks from that server
  before you set the URL and never took github.com ones.
