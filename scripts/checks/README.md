# CI gates

One line per gate. Each runs from the repo root as `node scripts/checks/<name>`.

- `check-agent-inventory.mjs`: an agent named in the docs must be in docs/integrations/agent-inventory.json, without an overclaim.
- `check-api-root-calls.mjs`: src/api reaches storage through ctx.store, not through a src/store function.
- `check-caught-error-logs.mjs`: log calls inside catch blocks and error listeners per file may fall, never rise.
- `check-cli-fail.mjs`: a CLI file ends in fail(), never an error print followed by a hand-thrown CliExit(1).
- `check-cli-flags.mjs`: a CLI file never turns a flag into text by hand; parseArgs may hand over `true`.
- `check-cli-recall-writes.mjs`: the CLI recalls through retrieveWithCliCore() and never ranks or records a recall itself.
- `check-comment-history.mjs`: ticket codes, version tags, dates and plan paths in src comments may fall, never rise.
- `check-config-reads.mjs`: only a surface file and src/host/config-file.ts read config.json through loadConfig.
- `check-dist-imports.mjs`: a script, benchmark, eval or test imports only dist files and names the build still makes.
- `check-domain-io.mjs`: src/base, src/domain and src/api import no fs, os or child_process, and domain and api no src/host at run time.
- `check-dts-diff.mjs`: api/hippo-memory.api.txt lists the published exports; `--write` updates it, `--check` verifies it.
- `check-em-dashes-in-release-notes.mjs`: the CHANGELOG.md entry of the version to publish holds no em dash.
- `check-env-reads.mjs`: only src/base/util/env.ts and the listed modules touch process.env.
- `check-error-text.mjs`: hand-spelled caught-error text per file may fall, never rise; use errorMessage().
- `check-expiring-keys-floor.mjs`: each store floor constant names a release that exists.
- `check-floating-api.mjs`: src and tests never drop the Promise of an api write function.
- `check-floating-promises.mjs`: a promise call in src is awaited or handled.
- `check-folder-cycles.mjs`: no two src features import each other at run time.
- `check-graph-writes.mjs`: only the two graph writers in src/store/sqlite/graph write the graph tables.
- `check-layers.mjs`: a src file imports only from its own layer or a lower one (layers.json).
- `check-lint-ratchet.mjs`: oxlint hits per rule may fall, never rise.
- `check-manifest-versions.mjs`: every JSON manifest declares the version about to be published.
- `check-migration-line.mjs`: each migration version is the previous plus one, except the gaps listed for next/3.0.
- `check-open-core.mjs`: a change adds no commercial-only file or identifier to the MIT repo.
- `check-openclaw-dist.mjs`: each `.ts` openclaw.extensions entry has a compiled dist twin Node imports as ESM.
- `check-positional-params.mjs`: no declaration in src takes six or more positional parameters.
- `check-process-exit.mjs`: src gains no process.exit call outside the list.
- `check-request-path-timing.mjs`: request-path work at 10,000 memories per store stays inside its time budget.
- `check-roadmap.mjs`: ROADMAP.md holds unique initiative ids, valid references and local anchors.
- `check-row-casts.mjs`: src and tests cast no SQLite read to a row shape nothing proves.
- `check-size-ratchet.mjs`: no file over 800 lines, no function over 50, no src line over 120 columns beyond the baseline.
- `check-store-port.mjs`: every server route reaches the database through the store port.
- `check-test-env.mjs`: a test never writes process.env by hand; it uses vi.stubEnv.
- `check-test-only-exports.mjs`: a src export that only a test names is removed or used.
- `check-test-stores.mjs`: a test builds a store through the shared helpers, not by hand.
- `check-tests-pass.mjs`: the test suite passes before `npm publish`.
- `check-token-drift.mjs`: legacy dark-observatory hex codes appear only in the token sources.
