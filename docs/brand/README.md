# Brand studies (2026-09-24)

Open the HTML files in a browser. They load three.js r128 from cdnjs, with jsdelivr as a fallback.

- **`2026-09-24-logo-studies-round1.html`:** five three.js marks: Spiral, Half-life rings, Fading h, Recall crystal, Low-poly hippo. Each has lockups and favicon previews. The Spiral was chosen and is on the site: `website/scripts/make-logo.mjs` draws the flat mark, and `website/src/components/MemorySpiral.astro` renders the live one.
- **`2026-09-24-logo-studies-round2-3d.html`:** six physically lit marks you can drag to rotate: chrome spiral, glass orb, extruded h, strata, recall knot and spiral pebble. The final pick is still open.
- **`round3/2026-09-25-logo-round3.html`:** still renders from three.js 0.180 of the Recall spiral (the pick), Memory string, Half-life rings and The h, plus app-icon tiles at real sizes. Regenerate with `python render.py` then `python sheet.py`, both in `round3/`.
- **`round4/2026-09-25-logo-round4.html`:** flat-first round. Three hand-built SVG marks (Echo h, the pick; Decay h; Curl) with app-icon tiles at 180/60/48/29, favicon at 32/16 and a Martian Mono wordmark. Sources `echo-h.svg`, `decay-h.svg`, `curl.svg`, `favicon.svg` sit next to it. Regenerate with `python finalists.py` then `python sheet.py` in `round4/`; `hero.py` renders the matte three.js version that was dropped.
- **`round5/2026-09-25-logo-round5.html`:** three.js only, no flat marks. Echo h (the pick) as bone ceramic with a frosted mint echo lit from inside, Curl and Coil as the other finalists, app-icon slabs at 180/60/48/29 on dark and light, and a Martian Mono lockup. `live.html` orbits the pick (serve the folder over http). Regenerate with `python render.py finals` then `python sheet.py` in `round5/`.
- **`round6/2026-09-25-logo-round6-mockups.html`:** eight different styles, all in three.js: Surfacing, Memory dust, Sediment, Liquid chrome, Tiny world, Mascot, Half-life type and Holo card. Each is shown on a phone home screen, a site header, GitHub and a sticker. Each style folder holds `hero`, `icon`, `mark`, `alt`, `notes.md` and its scene; rebuild the page with `python mockups.py` in `round6/`.
- **`round7/2026-09-26-logo-round7-mockups.html`:** abstract patterns, no faces, all in three.js: Flow (a curl-noise strand vortex), Bauhaus (an h from primitive solids), Turing (a Gray-Scott reaction-diffusion slab) and Interference (wave rings). Same mockup layout as round 6; rebuild with `python ../round6/mockups.py .` in `round7/`.
- **`site-mockups/`:** the five homepage directions, as Design canvas artboards (`.dc.html`): Lab Notebook, Night Recall, Platform Approved, Terminal Native and Hippocampus. The site was built from Terminal Native, with Platform Approved used for `/teams` and the receipts idea taken from Lab Notebook.

**Colour code:** mint `#7ce38b` means recalled, amber `#f2b84b` means marked wrong, on ink `#0b0f0c`. **Type:** Martian Mono and Onest.
