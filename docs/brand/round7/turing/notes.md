Name: Turing Tablet
Idea: A Gray-Scott reaction-diffusion pattern cast as relief, dense labyrinth on one side dissolving into sparse dots on the other, with a few surviving cells glowing mint where memory was recalled.
Weak: At 60 px the relief reads as texture, not a shape, so the icon leans on the dense-to-sparse gradient and one mint point, and the hero's ground reads grey-brown rather than true ink.
